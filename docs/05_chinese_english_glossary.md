# Chinese-English Glossary

The original database was created in a Chinese-language course, so the SQL
table and column names are kept in Chinese. This glossary helps readers
understand the main database terms.

## Tables

| Chinese name | English meaning |
|---|---|
| 出版社 | Publisher |
| 作者 | Author |
| 會員 | Member |
| 書籍 | Book |
| 書籍作者 | Book-Author |
| 會員電話 | Member Phone |
| 購物車 | Shopping Cart |
| 訂單 | Order |
| 訂單明細 | Order Detail |
