# Learning Journey

## Stage 1 - Midterm: building the database

For the midterm project, I started with the basic database design.

I:
- wrote the business idea
- drew an ER diagram
- changed the ER design into relational tables
- studied 1NF, 2NF, and 3NF
- created tables with primary keys and foreign keys
- inserted sample data
- practised simple SELECT, WHERE, and ORDER BY queries

This stage helped me understand how tables are connected.

## Stage 2 - Final: adding more SQL features

For the final project, I used the same online bookstore database and added
more features.

I:
- created VIEWs to combine data from several tables
- created a sales summary VIEW
- added an INDEX to the book title
- used EXPLAIN before and after the index
- practised transactions with COMMIT and ROLLBACK
- created a stored procedure to calculate a member's total spending

The final project helped me move from basic database design to more practical
SQL operations.
