# Project Overview

## System idea

This project is a simple online bookstore database.

Members can browse books, check information about authors, add books to a
shopping cart, and place an order. The database also stores delivery
addresses and order status.

The main users are:
- Members
- Bookstore staff

A simple order process is:

`register as a member -> search for books -> add to cart -> place an order -> shipping`

The project focuses on the database structure and SQL operations.
